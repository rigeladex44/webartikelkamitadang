Pengaturan Backend Supabase

Sinkronisasi data portal multi-subdomain ke cloud database

Status Koneksi Supabase
Masukkan Project URL dan Anon Public Key dari project dashboard Supabase Anda.
Skema SQL Multi-Subdomain (schema.sql) 
-- 1. Buat Tabel Sites (Subdomain)
CREATE TABLE IF NOT EXISTS public.sites (
    id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
    slug TEXT UNIQUE NOT NULL,
    name TEXT NOT NULL,
    tagline TEXT,
    description TEXT,
    logo_badge TEXT DEFAULT 'KD',
    theme_color TEXT DEFAULT '#2563eb',
    created_at TIMESTAMPTZ DEFAULT now()
);

-- 2. Buat Tabel Articles dengan site_slug
CREATE TABLE IF NOT EXISTS public.articles (
    id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
    site_slug TEXT NOT NULL DEFAULT 'main',
    title TEXT NOT NULL,
    summary TEXT,
    category TEXT NOT NULL DEFAULT 'Nasional',
    tags JSONB DEFAULT '[]'::jsonb,
    content TEXT NOT NULL,
    author TEXT DEFAULT 'Redaksi KAMIDATANG',
    image TEXT,
    caption TEXT,
    dateline TEXT DEFAULT 'JAKARTA, KAMIDATANG',
    status TEXT NOT NULL DEFAULT 'Terbit',
    is_main_headline BOOLEAN DEFAULT false,
    is_sub_headline BOOLEAN DEFAULT false,
    views INTEGER DEFAULT 0,
    comments JSONB DEFAULT '[]'::jsonb,
    date TEXT,
    time_ago TEXT DEFAULT 'Baru saja',
    created_at TIMESTAMPTZ DEFAULT now()
);

ALTER TABLE public.sites ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.articles ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Public read sites" ON public.sites FOR SELECT USING (true);
CREATE POLICY "Public write sites" ON public.sites FOR ALL USING (true);
CREATE POLICY "Public read articles" ON public.articles FOR SELECT USING (true);
CREATE POLICY "Public write articles" ON public.articles FOR ALL USING (true);

Pengaturan Google AdSense & ads.txt

Monetisasi terintegrasi untuk kamidatang.com & seluruh subdomain

Google Auto Ads Multi-Subdomain
Setelah domain utama kamidatang.com disetujui Google AdSense, seluruh subdomain tim Anda otomatis menayangkan iklan dengan satu Publisher ID yang sama tanpa perlu review terpisah.
Aktifkan Google Auto Ads
Google AI otomatis menganalisis tata letak berita dan menempatkan iklan terbaik.
• 
google.com, pub-0000000000000000, DIRECT, f08c47fec0942fa0

Tempatkan file ads.txt ini di root direktori hosting web Anda (https://kamidatang.com/ads.txt).

Checklist Kesiapan Pengajuan Google AdSense:
  • Kebijakan Privasi: Sudah aktif di footer portal (memuat klausul Cookie DART & AdSense).
  • Pedoman Media Siber & Kontak: Sudah aktif sesuai standar Dewan Pers.
  • Isolasi Subdomain: Subdomain tim fokus pada artikelnya sendiri tanpa distraksi internal.
  • Auto Ads AI: Otomatis menyesuaikan perangkat (Mobile & Desktop).
